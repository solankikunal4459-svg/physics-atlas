# Physics Atlas

An interactive web app for chapter-wise categorisation of Class 11 & 12 Physics content.

## What it does

Physics Atlas categorises each chapter into:

- Definitions
- Formulas
- Laws & Principles
- Derivations
- Concepts
- Graphs
- Applications
- Other categories

Select a chapter to see the distribution through an interactive pie chart. Click a category to explore the corresponding records.
